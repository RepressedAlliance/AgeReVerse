## Windows 字体也如实登记

楷体 KaiTi、宋体 SimSun、MS Mincho、微软雅黑 Microsoft YaHei 出现在实际图片制作或候选中；SimHei、MS Gothic 还有字体比较记录。它们是 Windows 授权字体，**不能统称为开源字体，也不在本仓库附送字体文件**。

Microsoft 的[字体再分发说明](https://learn.microsoft.com/en-us/typography/fonts/font-faq)区分渲染后的图形和字体软件：在适用授权条件下，词句的图片可以用于游戏；这不等于允许复制字体文件、转换字体格式，或把逐字导出的字形库作为游戏字体分发。新制作优先选来源与许可明确的开源字体；确需其他字体时，记录具体授权依据和交付方式，不因“系统装了”就推定任何使用方式都获准。

## 图片致谢和随包许可证分别处理

本项目要求公开登记图片用字，便于感谢作者、维护样式和追溯替换。**这是项目制作规范，不是声称每张 OFL 字体图片依法都必须附许可证。** OFL 官方[使用说明](https://openfontlicense.org/how-to-use-ofl-fonts/)明确区分图形作品与字体软件：单纯用字体制作图片不要求为图片附 OFL 声明，也不会让图片自动变成 OFL。

如果发布包、可编辑素材或工具实际携带字体文件，则按该文件的许可保留完整版权与许可证；修改、补字、子集或格式转换也按对应条款处理，包括适用的保留字体名。不能用本页、一个 OFL 网页链接，或另一款字体的许可证代替随字体交付的声明。本目录现有 `NotoSansSC-OFL.txt` 只保留其自身的来源关系，不是所有字体的通用授权书。

生成、手绘、借用原图字形分别写明方式；有使用字体作排字底稿或参考输入时也登记该输入，不因为最后经过图像编辑就抹掉来源。仅凭“看起来像某字体”不追认字体身份。
