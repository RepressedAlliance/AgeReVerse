# 图片复审协作

本文件适用于光子之花、光子旋律、TDA00–03 和帝都燃烧的图片制作与复审，包括对应的本地制作资料。按[自检与返修](04-self-review.md)和[审核与交付](05-human-review-and-delivery.md)工作。

- 所有看图、视觉质量判断和返修复审均由 **GPT-6 Astra 子代理**实际看图。主代理负责取材、按同类分组、调度、技术核对和汇总。
- 同一张复杂图分给不同的 Astra 并行独立审核。原意、漏译和术语，字形、字号和排版，以及透视、光影和画面修补分别有人负责。先各自记录看过的版本、问题位置和证据，再汇总。需要时找另一位 Astra 复核分歧。
- 规则明确的简单图按组批量核对，Astra 抽看不同布局和状态。发现同族问题就扩大复查。还要把清单之外的内嵌背景、旧稿和缺稿纳入取材，并保留适用的已验收结论。
- 能确认的问题先修。由未参与制作的 Astra 复查返修稿和受影响的同组图片。主审完成后把真正需要维护者取舍的图集中交付，已复核图按组供快速浏览。准确记录实际看图、打包和实机的状态。
