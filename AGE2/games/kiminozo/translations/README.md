# 君望文本

此处是君望可公开文本及校对样例的维护位置。目前尚未提交正文数据表，
`project.toml` 的 `translation_authorities` 因此为空，不用空白 CSV 表示已完成的译文。

后续导出分别组织本篇 `kiminozs` 与附加篇 `kiminoaz`，每条记录保留组件、脚本、
文本 ID 和源文本哈希。版本间 ID 可能变化，需要核对原文和上下文，不能只按 ID 对齐。
控制符及换行决策也须随记录保留，不在导出时批量删除。

沿用 LE 的旧译全文不在此公开；允许公开的纠错和必要样例，应说明修改前后、理由与适用位置。
新增／调整文本继续完成维护者的最终审核，并确认全文公开范围后，才建立对应正文入口。
AI 建议、维护者确认、实际写回和补丁发布是不同状态，不能相互代替。
