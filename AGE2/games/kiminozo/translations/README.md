# 君望文本

[返回项目入口](../README.md) · [翻译工作流](../../../../Localization-MakeGamesSpeak/Text-AITranslationWorthReading/README.md)

本篇 EE、社区 EER 1.0 适配和 AEC+ 的中文已随 1.0.0「再会」交付。新增／调整文本经过 AI 工作流及木之全文人工校对；旧译纠错由 AI 协助检查、木之审核修订。

这里维护允许公开的术语、校对样例及其定位。完整旧译、完整改写后正文表与内部审校资料继续保留在私有制作区，`project.toml` 的 `translation_authorities` 因此为空。正文未公开不表示翻译未完成，也不以空白 CSV 冒充权威表。

制作记录分别组织本篇 `kiminozs` 与附加篇 `kiminoaz`，保留组件、脚本、文本 ID 与源文本哈希；跨版本定位须同时核对日文及上下文，不只按 ID 对齐。必要样例应包含日文原句、修改前后与理由，避免截去语境导致误解。控制符和换行随记录保留。

AI 的 `keep/revise/question` 是审校建议，最后采用表达由人工决定；发布包、写回资源与讨论中的候选须分清。反馈中的小段原句和必要语境可以用于定位，不上传全文或私人通信。
