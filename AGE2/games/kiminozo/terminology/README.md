# 君望术语与基线

[返回项目入口](../README.md) · [通用本地化规范](../../../../localization/text/README.md)

此处维护君望作内术语、语境基线和相关用典说明。当前工作表仍在审核，尚未导出公开 CSV。
首次公开时，术语表与基线表分别保存，并在项目清单中登记实际文件路径。

- **术语表**：按是否为专有名词、是否需要全文统一收录，不以出现次数决定；
  明确的组织名、人名等采用确定译法后统一维护。
- **基线表**：记录语境、上下文、采用译法及判断理由。同一日文在不同语境中可以有不同译法，
  不作为全局机械替换表。
- **固定表达**：需要反复呼应的咒语等，可作为例外统一登记，并说明适用范围。
- **用典说明**：区分原典、游戏内改写、官方中文用法、社区用法和维护者判断，
  不把尚未确认的出处写成确定事实。

旧译者建议与维护者取舍应落实为对应条目的来源和理由；公开记录使用必要摘录，
不附私人邮件和聊天原文。
