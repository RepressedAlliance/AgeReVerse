## 收录与使用

- **术语表**：看是否为专有名词、是否需要全文统一，不以出现次数决定。人名、组织、特定称号等只在同一对象的范围内固定；敬称另看人物关系。
- **基线表**：包含确认术语及其依据，也保留语境译法、候选和判断理由，同一日文在不同语境可以另译。完整称号、敬称、一般职务和普通表达不因出现多次就成为专名。
- **固定表达**：遥的四句咒语作为例外进入术语表，保留八字节奏；第三句统一“即使双手已经放开”，停顿随演出处理。
- **用典**：区分已采用的中文表达和出处判断。地底都市不附加GeoFront，现有材料不足以确认特指EVA；不把推测写成作者确认。

本版已经同步后续审核采用的竹尾竹雄、竹卡斯、BattleTech、二弟、完整过膝袜称号、一次性胶卷相机，以及音响语境中的CD。基线另补亚由「あに」、伴手礼、伪君子和精神上的尊卑关系四项用法。表内采用决定不表示相关资源或安装包已经重建。

主基线有现行术语167条，语境参考186条，待核问题3条，候选3条，其他来源／语境译法1条。`term`记录现行术语，语境和参考项不代表全文同译。三个小队呼号仍为候选。名古屋打ち当前保留“小蜜蜂”，“名古屋打法”留作待请教候选；室内度假设施名及夢の島的解释也继续标为待核，不参与现行术语加载。

同一日文可以保留多条不同依据。例如`セルヅオ越後`既有“塞尔吉奥·越后”的确认定名，也保留整句语境译法供查证，因此360条记录对应359种日文写法。

```powershell
python localization/tools/terminology.py kiminozo --term タケス
```

工具只读取本作术语，基线及候选不会自动加载或替换正文。表的条目数不是全篇审校完成度。

## 原始来源与定位

以下九列来源记录保存在[来源表](history/evidence-20261009.csv)中；主基线用六列整理后关联这些记录。

本版按截至2026-10-09的审校整理结果导出：术语表对应已整理的167条定名与固定表达；基线收录这167条确认术语的译法、范围与定位，并保留189条语境工作记录和后续已采用的4项用法。表中注明判断、范围及必要出处，不公开完整场景原文。

| 来源表`source` | 本版记录数 | `source_row`含义 |
| --- | ---: | --- |
| `kiminozo-context-20261009` | 189 | 此版本语境整理表的记录编号，含表头从1计 |
| `kiminozo-review-20261009` | 4 | 后续补入用法的记录编号，含表头从1计 |
| `kiminozo-glossary-20261009` | 167 | 本版公开术语表的记录编号，含表头从1计；`basis`保留该条术语的`context` |

`source_row`用于追溯整理记录，不是游戏台词编号。具体游戏定位写在术语的`context`或基线的`basis`中：`kiminozs`为本篇，`kiminoaz`为番外；`资源目录／脚本／game_t编号`共同确定台词。姓名栏等没有文本ID时保留脚本及脚本行编号。`LE 数字:数字`为旧译参考定位，不能当作EE文本ID；只见于LE的用法会注明参考性质。

`occurrences`未作统一统计，留空表示未统计，不是零次。公开表保留必要词形、采用表达及定位；不上传旧译全文、官方完整脚本、私人邮件、聊天或内部审校附件。感谢木之老师提供旧译并持续参与纠错、术语与用典讨论。

## 精简主基线的读法

主表六列为`jp,cn,kind,chapter,basis,evidence_rows`。现行术语167条，语境参考186条，待核问题3条，候选3条，其他来源／语境译法1条。每条现行术语只保留一条；相同日文、中文及类别合并来源，不同中文或候选／待核状态分别保留。

`basis`保留完整使用限制；`chapter`是来源已知的篇章范围，不能代替使用限制。`evidence_rows`是本目录来源CSV的记录编号，以分号分隔，含表头从1计，不是游戏台词编号。旧来源的状态和出现次数原样保留，次数不跨来源相加。原已排除及明确误命中的资料只留在来源表，未审候选不自动确认。

[整理明细](review-20261009.md)列出数量变化和资料限制。默认查主表；`--term`同时返回当前术语与关联来源，程序不必解析说明文字：

```powershell
python localization/tools/terminology.py kiminozo --baseline
python localization/tools/terminology.py kiminozo --baseline --term ほんとうのたからもの
python localization/tools/terminology.py kiminozo --baseline --history
python localization/tools/terminology.py kiminozo --check-baseline
```
