# 君望／你所期望的永远 Steam 简体中文汉化计划（制作中）

[返回首页](../../../README.md) · [AGE2 项目](../README.md) · [项目清单](project.toml)

《君望》（Kimi ga Nozomu Eien ~Enhanced Edition~）Steam 版简体中文汉化正在制作中，
范围包括本篇及 Another Episode Collection+。**本项目尚未发布君望补丁，暂时没有安装包。**
GitHub 的 Source code ZIP 不能安装汉化，其他作品的安装器也不适用于君望。

## 当前进度

截至 2026-09-28，已完成全篇文本对应、场景阅读，以及新增／调整文本的初翻；
既定二审范围已有逐条结果，维护者正在审阅二审后的修订建议。
我们也在与旧译者木之老师沟通旧译纠错、术语和用典处理。

UI 和图片汉化正在制作与复核，字体已完成选型；资源整合、最终字体写入、
安装包制作和实机验证仍需继续。完成文本审核不等于补丁已经可以发布。

## 术语与基线

截至2026-10-09，公开整理了[本作术语表167条](../../../Localization-MakeGamesSpeak/Glossaries-KeepItConsistent/kiminozo.ja-zh-Hans.csv)和
[基线360条记录](terminology/baseline.ja-zh-Hans.csv)。术语集中维护，基线留在本目录；
[使用说明](terminology/README.md)列出来源、状态及适用范围。

术语按专名及全文统一需要收录，遥的四句咒语作为固定表达例外登记；基线是术语的父集，包含全部167条确认术语的依据，以及193条语境、候选和待核记录。
两张表覆盖本篇及番外的已有整理结果，后续随审核更新，不代表全文审核完成或安装包已经发布。

## 翻译来源与公开范围

感谢木之老师提供的 LE 旧译，以及在旧译校对、术语和用典方面给予的帮助。
本项目以日文原文为依据，结合旧译进行版本对应、校对及新增／调整文本翻译，
由 AI 协助处理并由维护者审核、决定最终采用的表达。

旧译全文不放入公开仓库。校对记录、术语和必要样例按已确认范围整理；
新增译文完整文本的公开范围尚待单独确认。本目录公开项目结构、状态、术语与语境基线，
不上传邮件、私人聊天、内部审校记录或游戏原始资源。
