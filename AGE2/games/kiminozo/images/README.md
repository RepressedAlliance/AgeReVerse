# 君望 UI 图片与字体

[返回项目入口](../README.md) · [通用字体政策](../../../../Localization-Make-Games-Speak/Fonts-That-Fit-The-Game/README.md)

此处维护君望 UI、图片文案、资源对应及最终采用的字体配置。图片汉化正在制作与复核，
当前还没有可供构建的公开资源清单，也未发布字体或图片二进制。

资源记录按 `kiminozs` 与 `kiminoaz` 分开，保留完整逻辑路径、原图尺寸、
中文文案、审核状态与目标语言。原图、无字底、候选图及实际采用图需要能明确区分；
原文相同但尺寸或使用位置不同的图片，不能只凭文件名合并。

字体按正文、姓名栏、界面与片尾等实际用途记录。选型完成后仍需验证字形覆盖、字号、
断行和游戏内显示，才登记最终写入配置。字体名称和许可证随采用方案公开，
字体文件仅在许可允许时随发布物分发。

最终资源清单、构建输入和安装路径将在整合验证后补入；游戏原图、完整容器及
内部候选图不因建立本目录而转为公开发布物。
