# 君望 UI 图片与字体

[返回项目入口](../README.md) · [通用字体政策](../../../../Localization-MakeGamesSpeak/Fonts-ThatFitTheGame/README.md)

1.0.0「再会」安装包包含 EE、可选社区 EER 1.0 及 AEC+ 的中文图片与字体覆盖。系统界面、菜单以及场景内嵌文字均属于汉化范围，不只处理影响基本理解的图片。

资源按 `kiminozs` 与 `kiminoaz` 分开记录，保留完整逻辑路径、尺寸、中文文案、采用状态与目标语言。原图、无字底、旧候选与最终图明确区分；原文相同但尺寸或用途不同的资源分别处理。Release 安装清单记录每个实际输出的路径、大小与摘要，原图、完整容器和内部候选不因此公开。

标题菜单的共同字号、基线及分组左缘见[排版配方](title-menu-layout.md)。文案宽度不能决定菜单项左边缘；正常、悬停和按下状态沿用相同几何，避免中文短项发生偏移。该公开配方包含文案、几何与状态参数，不等于完整游戏素材。

字体按正文、姓名栏、界面等用途配置。安装包随实际字体保留版权与许可证；图片用字的来源见[字体致谢](../../../../Localization-MakeGamesSpeak/Fonts-ThatFitTheGame/attribution.md)。制作和资源核对不能替代全路线实机遍历，已完成的检查与未覆盖范围以发布说明为准。
