# 君望标题菜单排版

`title-menu-layout.json` 描述 EE／社区 EER 的 38 张标题菜单资源，映射两版本共 74 个目标。普通态与高亮态共用文字、字号、排版原点和基线；仅状态效果不同。

旧制作脚本把每句日文的墨迹边界分别当作中文排版框。日文字形的起笔位置不同，导致“特别内容”等中文行额外右移，同时出现字号差异。现在以字体“国”字的共同墨迹高度确定字号，以菜单组固定原点排版，不再按各句原文的边界缩放或定位。主菜单与章节菜单分别保留自己的原点。AEC+ 的框按钮、图标下文字和设置项采用各自的居中布局，不适用这份左对齐配置。

复现需要 Python 3、fontTools、Node.js 和 Sharp，以及配置指定 SHA-256 的朱雀仿宋字体文件。字体从其合法来源另行取得，不在本目录存放字体或游戏图像。

采用字体文件的内嵌声明为 Copyright 2023 JadeFoci、SIL Open Font License 1.1；制作方为 TrionesType／璇玑造字，作者为余俊益、韩泳思、殷叶航、李剑桥。此处记录实际输入的作者与许可声明，不以另一发行文件代替本配方指定版本。

```powershell
python AGE2/tools/images/kiminozo_title_layout.py --layout AGE2/games/kiminozo/images/title-menu-layout.json --font <字体路径> --output <新的输出目录> --node <node.exe路径> --sharp-module <Sharp包路径>
```

输出目录必须尚不存在。未提供 `--node` 时只生成 SVG 与状态配置。工具检查字体版本、字形覆盖、重复键和文字是否超出固定框。

配置状态为候选：生成结果应在相应版本的资源映射中替换整行，并检查原尺寸、缩放尺寸、普通态和高亮态。静态合成不能证明引擎中的调用、动画或任意窗口比例均已通过。

2026-10-23 的复现与已看图候选对比：37 张 RGBA 完全相同；EER 回想高亮因 JavaScript 与原 NumPy 浮点插值及透明像素的处理不同，可见像素最大差为每通道 1/255，alpha 完全相同。布局、字体和原高亮采样曲线均保留。该差异不应被表述为字节完全复现。
