# Public translation snapshot versus historical Release

## Unsafe assumption

A reviewed CSV, an installable historical ZIP and a reproducible current build
were initially treated as interchangeable proof. They answer different
questions.

## Distinct inputs

The maintained dialogue tables are bound to exact source fields without bulk official dialogue. TDA00–03 provide source-hash-to-local-EGPACK joins; Imperial provides a non-dialogue builder. These components do not alone reconstruct every speaker, choice, image, font, UI resource or historical ZIP byte.

## Production rule

- Label a table as translation authority, runtime contract or Release payload;
  never silently promote one role into another.
- Bind current public tables to exact bytes and hashes, but do not publish bulk
  official script merely to make the join convenient.
- Call a package reproducible only when every required input, transformation,
  output manifest and clean-install test is present.
- Record missing links as explicit release blockers instead of filling them
  from an old branch or workstation staging tree.

## Remaining boundary

The public AGE2 path is component-reproducible, not yet historical-ZIP
byte-reproducible. See the text-free review ledger for unresolved review
identities and [release compatibility](../../evidence/translations/snapshots/compatibility.md) for the supported scope.
