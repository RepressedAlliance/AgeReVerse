`rebirth-text.zh-CN.csv` 保存从原始离线画面核实的英文文字和中文初稿，
包括保密提示、技术标签、部件价格及旁白字幕，共63行。
此文件尚未接入打包器。现已确认日文图像语言的视频本来就有英文技术标签、价格及
保密提示，应按项目原则保留。最终制作仅替换 Translation 分支新增的旁白字幕；
此前覆盖全部图文的中文试片保留为研究稿，不作为生产输入。字幕听校、画面与时序
处理、封装及音画验收仍未完成。

2.04、22px／400字重、1.1px黑描边及固定基线；未使用此前技术标签的神经修补底图。

仅通过原字形遮罩及羽化边缘替换底部像素。首轮缩小模板遗漏的句号描边已改用
原尺寸字形补捉。两行字幕的清除区域同样覆盖在505–589行内。此方法仍是近似
背景恢复，不能称为原背景逐字节重建。

1905帧中1658帧有修改，逐帧核对字幕修复及新字遮罩外无像素变化。
已查看全部22条字幕的原尺寸无字底／中文条带；已发现的标点残影在v2见证帧中
消失，样本中未发现明显裁字或网格断裂。连续运动、淡入淡出边界、日语听校、
生产CRsi封装与游戏内同步仍待完成。这是可审阅的试片，不能作为已完成补丁。

## 视觉制作与一致性

本演出沿用仓库的[图片汉化流程](../../../../localization/images/README.md)、
[视觉制作规范](../../../../localization/images/production.md)及
[图片字体目录](../../../../localization/fonts/images.md)。中文须自然融入原演出，
文字准确、能显示和编码通过均不能单独证明成品美观。

- 开场保密卡、技术标签、价格、旁白按视觉功能分组。每组统一字体文件及版本、
  字重、字号、字距、行距、基线、颜色、光晕和透明度曲线；同级标签跨眼部、
  手臂与腿部复用样式。保留标题、参数与价格之间的层级，不逐词拉伸或随意缩字。
- 先对照原片制作代表画面，比较字形气质、视觉重心、文字密度、留白及柔和程度，
  然后扩展到整组。图片字体不自动等于运行时正文字体；优先比较目录中已有的
  PM 制作字体，不能因默认字体可用就直接定稿。
- 无字底单独审查。网格须连贯，模型、线缆及轮廓须保留；旧字残光、弯线、
  糊块和补丁接缝都须返修，不能依靠新字遮挡缺陷。
- 制作原图／中文的整图、原尺寸及局部细节对照，检查已采用文案、数字与笔画，
  同时比较整组效果。原作语言的保留／翻译决定仍服从现行来源原则。
- 视频另外检查连续时间段：逐字出现的起点和节奏、价格闪烁、淡入淡出、
  镜头切换及修补纹理的时间连续性。固定文字的基线与位置不得随帧跳动，
  光晕不得突变，修补区域不得闪烁。漂亮的单帧不能代替连续演出检查。

历史全图文 v4 使用 Microsoft YaHei 的临时排字，只有可读性与部分布局抽查，
**尚未完成字体选型、原片风格匹配或美术验收**。已有28处文字的位置和尺寸
作为可返修草稿保留，不能视为已经确认的最终样式。开场、密集眼部标签、手臂／腿部
参数与价格、旁白先做代表性原图／中文对照，修正后再统一应用。

第一轮新样式已记录于 `rebirth-ending-style.json`，采用字体目录中已有的
Noto Sans SC 2.04 输入。技术标签统一25px／400字重，价格38px／400，
旁白22px／400；开场标题单独采用100px／300及28px字距。颜色与柔和光晕
按开场、技术标签、价格分组，字符保持原宽高比例。
`style_layers.py` 复用仓库的8倍采样、共同基线和可变字体工具，输出原尺寸RGBA文字层，
字体路径由调用方传入并核对目录中的身份，不依赖机器默认字体。

本机 `style-study-v2/review.html` 可切换开场、眼部、手臂和腿部四张代表图，
对照原片、当前无字底、v4与新候选，并按原尺寸或放大查看。
28处图中文字及22条旁白均已实际渲染：无缺字，文字和特效层均未越出画布。
这4张合成图已按原尺寸查看；开场光晕、文字间距及整体可读性有所改善，
但眼部等无字底仍有弯折网格和软化，需继续修复。静态候选将图中文字完整显示，
仅用于样式比较，不宣称复现该帧的动画状态，也未替换现有连续视频。

## 图中文字的来源确认

统一样式之前还须确认哪些原字应当替换。当前28处中文图文是制作研究，
不能据此认定原片的英文都属于英文版翻译。按[翻译原则](../../../../localization/principles.md)，
日文原作已有的英文应保留；它们不应进入去字、补网格及重新排字的生产范围。

离线脚本与原生比较分支已确定：结尾的 `CInt@568804` 为0时调用无旁白字幕视频
`CRsi@1715679260`，为1时调用带英文旁白字幕视频 `CRsi@27493704`。
同一变量也由语言选择脚本设置；该脚本所用原图已解码查看，明确有“English”
和“日本語”按钮。选择结果0写入1，选择结果1写入0。原生选择结束回调清空上一层
按钮列表；创建操作99以列表长度分配ID并在插入后递增。因此先建立的英文按钮
ID为0，后建立的日文按钮ID为1（两套作品主题图是互斥分支）。这补齐了静态
对应关系：变量0为日文图像语言，变量1为Translation。

**生产保留原片的保密卡、技术标签、价格及其动效，只替换Translation资源的旁白字幕。**
这遵守原作英文保留原则，不采用研究稿中的技术标签去字、修补和中文覆盖。
已有中文样式和修补候选保留为研究成果；旁白使用统一样式，并仍须依据对应日语音轨听校。
本次检查复用了265条脚本的索引，找到12处引用，全程离线，未启动或操作游戏。
结构化记录见 [语言分支证据](../../../evidence/photon/video/rebirth-language-branches-20261010.json)。

## 版本与帧号

| variant | 带英文字幕 CRsi 全局偏移 | 无旁白字幕 CRsi 全局偏移 | 总造价 |
| --- | --- | --- | --- |
| long | 27493704 | 1715679260 | 900万欧元 |
| short | 117665112 | 1808635048 | 600万欧元 |

脚本链已确认：`short` 出现在前段回忆之后、戈德曼简报之前；
`long` 出现在最终对话和职员表之后。
本任务的结尾替换对象是 `long` 的Translation资源，日文资源提供无旁白背景参考。
短版对照用于区分原片内容、参数和术语，
不能把600万版本当成结尾900万版本的语言变体。

`both` 表示两版都存在且共用该行文字。`long_witness_frame` /
`short_witness_frame` 是对应**英文字幕版本**中人工查看、可辨读的0起始见证帧，
不是入帧点、出帧点或字幕持续时间，也不可直接套用到无旁白字幕版本。
状态 `draft_visual_source_checked` 表示已核实该见证画面的来源文字，
中文仍为初稿。长版22条旁白字幕的连续边界已单独核实；
技术标签逐字动画的覆盖、日语音轨核对仍待完成。
现有本机 ASR 是辅助线索，不是已听校的日语原稿，也不能作为精确时间轴。

`layer` 区分 `notice`、`technical`、`price` 和 `subtitle`。
`body.*` 技术标签在手臂、腿部两处复用，当前见证帧取手臂画面；
实际制作须覆盖两处，不可按CSV行数当作画面出现次数。
眼部标题的“／”用于分隔标题与说明两行，像素布局见下述 layout 文件。

## 旁白字幕离线预览

`rebirth-ending-subtitles.frames.json` 记录长版英文旁白的22个0起始、右端不含帧区间。
逐帧检测后已查看每条的开始前一帧、开始帧、结束前一帧、结束帧。
最后一条在1859帧仅有极弱压缩残影，该帧不计入字幕正文。

原生 CRsi 默认时钟为 `MulDiv(frame, 100000, rate)`，本资源 rate=3000，
对应30fps；播放控制器的覆盖值及音画起点仍未验证。
两条长版视频存在局部帧差，不能把英文字幕版帧号当成无字幕版的精确画面对应。
当前预览只把这些区间按默认时钟转成名义时间，叠加于无旁白字幕版本并配原音轨。

```powershell
python -m rUGP.tools.video.subtitle_track --timeline rUGP/games/photonmelodies/video-localization/rebirth-ending-subtitles.frames.json --text rUGP/games/photonmelodies/video-localization/rebirth-text.zh-CN.csv --output ending-subtitles.ass
```

ASS 时间向下取整到厘秒，以保持30fps各帧时刻的事件归属。早期1904帧预览仅含
中文旁白；最新预览还包含以下技术标签、价格和保密提示。未完成音轨听校、
游戏内同步验证或生产 CRsi 编码，不能作为完成的汉化补丁。

## 技术文字布局与清除研究

技术文字的像素区域另见 `rebirth-ending-technical.layout.json`：
28个出现位置覆盖眼部13行、手臂6行、腿部6行、保密提示3行；眼部标题拆为两行，
`body.*` 在手臂和腿部分别列出。`target` 保存中文位置、字号、对齐和颜色。
这些位置只适用于无旁白字幕长版；`detection_span` 是检索窗口，
不是已验收的入出帧。参考帧提取的是字形核心，清除时还须处理抗锯齿和发光边缘。

```powershell
python -m rUGP.tools.video.overlay_masks --video '<原尺寸无字幕长版代理>' --layout rUGP/games/photonmelodies/video-localization/rebirth-ending-technical.layout.json --output-directory '<新的本机私有输出目录>'
```

分析器输出候选显示区间、逐帧强度与字形遮罩。价格包含闪烁，不能简单压成一个
持续显示区间；明亮模型可能影响淡出检测。输出含游戏派生像素，不应提交或公开。
单帧空间修补试片因网格和手腕损伤已否决；时序修复仍在本机评估，未成为生产素材。

`technical_track.py` 用字形覆盖率驱动中文逐字出现，用强度驱动亮度和闪烁，
两者分别计算，避免把开场呼吸亮度误当成打字进度。透明后缀保留整行宽度，
使右对齐文字在逐字出现时不横向跳动。每个适用文字ID必须被布局覆盖。

```powershell
python -m rUGP.tools.video.technical_track --layout rUGP/games/photonmelodies/video-localization/rebirth-ending-technical.layout.json --analysis-directory '<overlay_masks 输出目录>' --text rUGP/games/photonmelodies/video-localization/rebirth-text.zh-CN.csv --output '<新的技术文字 ASS 文件>'
```

`compose_repairs.py` 将原尺寸修复裁块合成到无损代理，逐帧核对输入裁块与源视频相同、
修复图中遮罩外像素完全相同，并拒绝遗漏输出、缩放输入和重叠时间范围。
当前四段共659帧裁块，合成后仍为1904帧1024×600；30fps是名义离线时钟。
这些检查证明合成范围，没有证明被修复区域的美术质量或游戏播放正确性。

开场平滑蓝色背景单独用 `notice_background.py` 从同帧四周边界插值恢复，
处理0–189帧的 `(224,136)–(800,432)` 文字及发光区域。字形遮罩会漏掉闪烁
和发光孤岛，大块神经修复也产生了不应存在的亮块，因此这些开场候选没有采用。
边界插值仅适用于这一简单背景，不适用于后面的模型和网格。

```powershell
python -m rUGP.tools.video.notice_background --video '<原尺寸无字幕长版代理>' --output-directory '<新的本机私有开场目录>'
```

最新本机预览 `ending-complete-text-draft-v4.mp4` 覆盖22条旁白和28处图中文字，
保留1904帧、1024×600和原音轨内容（预览转为AAC）。按序查看40个采样点，
开场先前漏出的英文和发光残块在这些采样中已消失，中文排版没有发现裁切。
眼部、手臂和腿部仍有网格软化、弯折和条纹，模型细节及连续时序尚待验收。
采样不等于完整视听检查；这些素材仍是制作草稿，尚未封装进游戏补丁。

## 必须保留的差异

- 长版代号 **Fenice**，短版 **Falso**；长版从死亡与绝望中重生，
  短版曾站在死亡深渊边缘。不能只替换总价与能力数字。
- 长版有 Alternative IV 技术强化句及 G-Code 预约录像功能，短版没有。
- 长版字幕说 reinforced concrete，短版为 concrete；分别译作强化混凝土／混凝土。
- 眼部造价长250万、短200万；手臂长250万、短150万；
  单腿长200万、短125万欧元。两版部件总价分别等于900万、600万欧元。
- 原图出拳数值是2.0／1.5 ton，小数点必须保留；当前按原图单位译作吨，未做单位换算。
