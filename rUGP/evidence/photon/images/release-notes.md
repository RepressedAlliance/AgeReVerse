# 光子之花 / 光子旋律图片研究资源 1,490 项（V6）

V6 是历史制作资源，不是可直接安装的补丁，也不代表当前玩家包的全部图片。**其中有 19 张 PNG 与官方源文件字节相同，分发整改尚未完成。** 复用范围与来源见[资源说明](README.md)；技术身份一致不等于取得再分发许可。

## 内容与使用

- 1,490 项 PNG，带资源 ID、尺寸与摘要清单。
- 1,247 项以当时正式候选 PNG 为来源。
- 243 项 PNG 从封存原生记录恢复，仅用于预览；包内对应原生记录才是封包输入，不应把预览图再次编码。
- `manifest.json` 与 `SHA256SUMS.txt` 用于按资源身份查找和校验。

不要用审核 JPG 作为图片源；继续修改时先确认现行文案、字体、配方和版本，旧 V6 候选不能直接覆盖较新资源。
