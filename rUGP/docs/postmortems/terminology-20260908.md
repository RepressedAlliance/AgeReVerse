# 术语统一：相似词形不一定是同一个意思

[术语工作流](../../../Localization-MakeGamesSpeak/Glossaries-KeepItConsistent/README.md) · [跨作品实例](../../../Localization-MakeGamesSpeak/Glossaries-KeepItConsistent/decisions.md)

Photon 的术语修正说明了为什么总表只能提供候选，不能替代日语与场景：

| 例子 | 采用与判断 |
| --- | --- |
| 激光级／重激光级 | BETA 类别统一为光线级／重光线级；普通レーザー仍可译“激光” |
| 美纪／Miki | 壬姫自称ミキ，不是另一位叫“美纪”的角色；结合说话人确定为壬姬 |
| Enigma、Rafale | 在对应技术语境采用恩尼格玛、阵风；不能脱离型号与同场景注音 |
| カマを掘られる 等粗俗口语 | 《赎罪》按语境采用“爆菊”；不把掘る加入全局强制替换 |
| ウィル、陽炎 | 前者会误中ウィルス，后者可能只是自然热浪；匹配后仍需判断词边界与语义 |

## 仍需结合现行表确认的历史分歧

2026-09-08 的记录列出以下差异，未给出全部统一后的关闭结论。它们保留为后续确认入口，不表示现行各作仍同时使用所有旧译：

| 现行译文 | 旧总表 | 处理 |
| --- | --- | --- |
| 皮亚蒂芙 | 皮亚蒂夫 | 角色名称与颜色识别相关，保留现行名称，待统一总表决定 |
| 伊尔芙莉德 | 伊尔弗里德 | 同上，不能只修改一个全名而留下短名和颜色别名 |
| 伊尔玛·特斯列夫 | 伊尔玛·特斯莱夫 | 音译差异待确认 |
| 伊隅晶 | 伊隅明 | あきら的采用译名待确认，不凭读音强制替换 |
| 卢瑟福力场 | 拉瑟福场 | 技术名词音译差异待确认 |
| 轨道降下兵 | 轨道潜水员 | 旧表译法本身需复核，不机械套用 |
| 母巢／巢穴 | 原始HIVE／HIVE | 类别及整套译名需统一决定 |

姓名全称、短名、颜色别名和图片不能各改一半；军衔、HIVE 分类及自然现象需整套按语境判断。应用改词时保留来源摘要、换行、控制符、人物包装和注音，以现行表建立新决定，不重写旧基线来掩盖差异。

## English

Glossary matches are candidates. Distinguish BETA classes from generic lasers, character nicknames from separate people, and proper names from ordinary words. The dated disagreement table remains a follow-up reference until checked against current sources; it is not a claim that every old form still appears in current releases.
