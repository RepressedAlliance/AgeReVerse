# 君望图片汉化成品预览

[正式版与制作说明](../../../../AGE2/games/kiminozo/README.md) · [下载 1.0.0「再会」](https://github.com/RepressedAlliance/AgeReVerse/releases/tag/kiminozo-1.0.0) · [全部汉化效果展示](../../screenshots.md)

《君望／愿此刻永恒／你所期望的永远》Steam EE、可选社区 EER 1.0 与 AEC+ 的中文补丁，承接木之 LE 汉化，由压抑同盟负责修订、移植、图片制作与统筹，并得到木之与 Muv-Luv Verse 社区制作者的支持。

## 素材类型与来源

以下两张取自 1.0.0「再会」采用的中文场景素材，属于已审核的图片汉化成品；**不是游戏运行截图，也不是日中实机对照**。它们于 2026-10-24 整理成文档用 JPEG，保持原始比例和画面范围，仅作压缩，没有新增文字、替换场景或改动成品内容。

| 图片 | 展示内容 |
| --- | --- |
| [祭典摊位与招牌](festival-localized.jpg) | 多块招牌、布棚、价签中的中文文字，以及透视、褶皱和遮挡关系 |
| [店内手写菜单](handwritten-menu-localized.jpg) | 中文菜名与笔触、纸面、纸钉及木墙的结合 |

图中展示的是选定素材的中文化效果，不代表所有路线或全部图片出现位置均已实机遍历。补丁的安装范围、版本检查与已知限制以正式版发布说明为准。普通 EE 可直接安装中文补丁；社区 EER 为补全删减内容的可选步骤，AEC+ 由同一安装器处理。

## 图片归属

游戏画面及原有内容归相应权利人所有；图片中文制作与修订属于本项目的本地化工作。木之的原译及校对、压抑同盟的修订与制作、Muv-Luv Verse 的社区 EER 补丁分别署名，具体范围见项目页。

这些预览不构成游戏资源包，不能用于安装补丁；仓库代码的 MIT 许可不覆盖游戏画面、中文图片或其他衍生内容。详见[内容权利说明](../../../legal/NOTICE.md)。
